# Enigma's Useful Tasty Mead

A Valheim mod. Drink a Tasty Mead and your active foods count as freshly eaten again. Your max health, stamina and Eitr jump back up to the full values your foods gave when you ate them, then fade smoothly back down to what your food really gives. It never heals you and never touches a food timer.

This repository holds the source code. The full description, settings and install instructions are in the [Release README](https://github.com/relinkem/Enigmas-Useful-Tasty-Mead/blob/main/Release/README.md), and that is also the page shown on Thunderstore.
